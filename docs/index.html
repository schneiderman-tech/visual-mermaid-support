FAQ

Does Confluence Cloud support Mermaid diagrams?

Not natively. Confluence Cloud shows Mermaid code as a plain code block, so you need an app such as Visual Mermaid to render it as a diagram.

Can I edit a Mermaid diagram without knowing the syntax?

Yes. Double-click a box to rename it, click + to add the next step and drag to connect boxes. The Mermaid code is rewritten for you and stays in sync.

How do I turn existing Mermaid code blocks into diagrams?

Open the page's ••• menu and choose Render all Mermaid code blocks.

Do readers need an account?

No. There is no extra account or login, and the app makes no external network requests.
