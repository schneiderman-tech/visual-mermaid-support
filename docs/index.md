# Free Mermaid editor for Confluence Cloud (no login)

**[Visual Mermaid Diagrams for Confluence](https://marketplace.atlassian.com/apps/1154212410/visual-mermaid-for-confluence)** lets anyone on your team draw and edit Mermaid diagrams by clicking, without learning the syntax. The Mermaid code stays in sync, so people who prefer code can still edit it as text.

[Get it free on the Atlassian Marketplace](https://marketplace.atlassian.com/apps/1154212410/visual-mermaid-for-confluence)

## Why teams pick it

- **Edit visually.** Double-click a box to rename it, hover and click **+** to add the next step, drag to connect boxes.
- **Keep the code.** Every click rewrites the Mermaid source; your comments and ordering are kept.
- **No login.** No extra account for authors or readers.
- **Nothing leaves Confluence.** Runs on Atlassian, no external network requests.
- **Paste from any AI.** Paste Mermaid generated by any AI tool and fix it by clicking.
- **Free for up to 10 users.**

## Already have Mermaid in code blocks?

Imported Markdown or pasted AI output often leaves Mermaid in plain code blocks. Open the page's **•••** menu and choose **Render all Mermaid code blocks**: each one becomes a live, editable diagram.

## How to add a diagram

1. Install Visual Mermaid from the [Marketplace](https://marketplace.atlassian.com/apps/1154212410/visual-mermaid-for-confluence).
2. On any Confluence page, type **/Visual Mermaid**.
3. Draw it, or paste Mermaid code.
4. Publish. Readers see a crisp diagram; click it for full screen with zoom.
